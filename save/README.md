# save/ — 프로젝트 저장 폴더

배관 영업 GIS에서 **"파일로 내보내기"** 한 프로젝트 JSON을 이 폴더에 커밋해서
보관·공유한다. 파일에는 수요처(마커)와 배관(세그먼트) 전체가 들어 있다.

## 사용법

- **저장**: 사이드바 *저장 / 불러오기* → 파일 이름 입력 → **저장**(브라우저에 보관) 또는
  **파일로 내보내기**(`<이름>.json` 다운로드). 받은 파일을 이 `save/` 폴더에 커밋하면 된다.
- **불러오기**: *파일 불러오기* → 이 폴더에서 받은 `.json` 선택.

## 형식

```json
{
  "version": 1,
  "savedAt": "ISO 날짜",
  "demands": [{ "id", "query", "address", "lon", "lat", "memo", "color", "shape" }],
  "pipes":   [{ "id", "coords": [[lon,lat]...], "segs": [{속성}...] }]
}
```

> 배포된 정적 사이트는 브라우저에서 GitHub에 직접 커밋할 수 없다(인증 토큰 필요).
> 그래서 내보낸 파일을 수동으로 이 폴더에 커밋하는 방식으로 저장소에 보관한다.
